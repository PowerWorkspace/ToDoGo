# ToDoGo 定时提醒

一个用 aardio 写的 Windows 桌面定时提醒小工具。到点自动弹窗提醒，支持每周循环、指定日期、延迟提醒，可最小化到系统托盘后台运行。

## 功能特性

- **添加定时事件**：填写事件内容，选择时间（时、分），一键添加
- **周期灵活**：支持"今天"、"指定日期"、"每周一到周日"多种周期
- **重复提醒**：勾选"重复"后，每周循环或每天循环
- **到点弹窗**：时间一到自动弹出提醒窗口，显示事件内容
- **延迟提醒**：弹窗时可选"延迟 5 分钟"或"延迟 10 分钟"再提醒
- **最小化到托盘**：点关闭按钮不退出，缩到系统托盘后台继续运行
- **开机自启动**：勾选后随 Windows 自动启动
- **删除事件**：选中列表里的事件，一键删除

## 使用说明

1. 下载 `ToDo.exe`，双击运行（无需安装）
2. 在输入框填写事件内容
3. 选择时间：左边选日期，中间选小时，右边选分钟
4. 勾选周期：今天 / 指定日期 / 每周几（可多选）
5. 是否需要重复提醒（勾选"重复"）
6. 点「添加」，事件就出现在下方列表里
7. 到点后会自动弹窗提醒

### 弹窗按钮说明

- **知道了**：本次提醒结束，重复事件会安排下一次
- **延迟 5 分钟**：5 分钟后再提醒一次
- **延迟 10 分钟**：10 分钟后再提醒一次
- 默认窗口置顶，达到强提醒作用

## 界面说明

- **static12（顶部）**：实时显示当前日期和时间
- **checklist（列表）**：显示所有已添加的事件（序号、时间、内容、周期）
- **开机自启**：勾选后开机自动运行
